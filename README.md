# GestorAlumnos
Aplicación de consola en **Kotlin** para gestionar la información básica del alumnado de un grupo: registrar estudiantes, almacenar sus notas, calcular la media y filtrar automáticamente al alumnado aprobado y suspenso.

```
└── ...
```

## Requisitos

- JDK 17 o superior
- IntelliJ IDEA (Community o Ultimate) con el plugin de Kotlin
